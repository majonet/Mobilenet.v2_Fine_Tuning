# MobileNetV2 SSD Lite Fine-Tuning Project

## Overview
This project fine-tunes the MobileNetV2 SSD Lite object detection model using PyTorch.

The project includes:
- Custom VOC-style dataset loader
- Data augmentation pipeline
- SSD prior box generation
- MultiBox loss implementation
- Modular training pipeline
- Transfer learning setup

##Dependencies
- Python
- PyTorch
- TorchVision
- OpenCV
- NumPy
